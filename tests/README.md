# Testes manuais do MVP

1. Abrir a home e navegar para o catálogo.
2. Buscar `Equação do 2º Grau` e filtrar por Matemática.
3. Abrir o roadmap, concluir etapas e recarregar a página.
4. Abrir uma etapa, marcar objetivos e ativar o modo de foco.
5. Testar links externos e navegação anterior/próxima.
6. Reduzir a janela para validar o layout móvel e navegar apenas pelo teclado.

A máquina de desenvolvimento atual não possui PHP instalado, então a validação de execução deve ser feita após instalar PHP 8+ ou em um ambiente com servidor PHP.
